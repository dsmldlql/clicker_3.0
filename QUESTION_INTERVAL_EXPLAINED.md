# question_interval — Подробное объяснение

## 📖 Что это?

**`question_interval`** — это **минимальная задержка между началом спрашивания двух вопросов подряд**.

Измеряется в **секундах**.

## ⚙️ Где задаётся

В `config_bots.yaml` для каждого бота:

```yaml
bot_0:
  project: hypos_norm
  site: qwen
  question_interval: 5.0      # ← 5 секунд между вопросами
  row_range: [990, 999]
  max_questions: 100
```

## 📊 Примеры значений в конфиге

| Бот | question_interval | Описание |
|-----|-------------------|----------|
| bot_0-5 (qwen) | 5.0 сек | Короткий интервал для быстрых моделей |
| bot_6-9 (gpt) | 45-60 сек | Средний интервал для GPT |
| bot_0-1 (gemini) | 220 сек | Длинный интервал для Gemini Thinking |
| bot_3_-6_ (claude) | 150 сек | Средний интервал для Claude |

## 🔄 Как работает: Пошаговый алгоритм

### Шаг 1: Бот задаёт вопрос

Когда бот достигает состояния `ask_empty` или `ask_json` (отправка вопроса):

```python
# scripts/bot_logic.py, строка 576
bot.last_question_start_time = time.time()  # ← Запоминаем время начала
```

**Что происходит:**
- Бот копирует промпт в буфер обмена
- Кликает по полю ввода
- Вставляет текст (Ctrl+V)
- Нажимает Enter
- **Запоминает текущее время** в `bot.last_question_start_time`

### Шаг 2: Бот получает ответ и переходит к следующему вопросу

После успешной верификации JSON бот переходит в состояние `start_question`:

```python
# scripts/bot_logic.py, строка 396
if next_state == 'start_question':
    if self.question_interval > 0 and bot.last_question_start_time is not None:
        time_since_last_question = time.time() - bot.last_question_start_time
        
        if time_since_last_question < self.question_interval:
            # ← Интервал ещё не прошёл!
```

### Шаг 3: Проверка интервала

**Вариант A: Интервал ещё не прошёл**

```python
# Вычисляем сколько ещё ждать
remaining = self.question_interval - time_since_last_question

# Устанавливаем время возобновления
bot.interval_resume_time = time.time() + remaining

# Устанавливаем флаг ожидания
bot.waiting_for_interval = True

# Сбрасываем таймер
bot.last_question_start_time = None

# Выходим без выполнения reset_scenario
print(f"[*] [Бот {self.bot_id}] Ожидание интервала между вопросами: {remaining:.1f}с (интервал: {self.question_interval}с)")
return
```

**Что происходит:**
- Бот **НЕ перезагружает страницу** (reset_scenario не выполняется)
- Бот **НЕ начинает следующий вопрос**
- Бот **ждёт** пока не наступит `interval_resume_time`

### Шаг 4: Ожидание (только в main.py)

**В main.py** (запуск всех ботов сразу):

```python
# main.py, строки 257-268
for bot_idx, (bot, fsm) in enumerate(zip(bots, logics)):
    if bot is None or fsm is None or bot.stop_event.is_set():
        continue
    
    # Проверяем, ожидает ли бот завершения интервала
    if hasattr(bot, 'waiting_for_interval') and bot.waiting_for_interval:
        if hasattr(bot, 'interval_resume_time') and current_time >= bot.interval_resume_time:
            # ← Интервал истёк!
            print(f"[+] [Бот {bot_idx}] Интервал истёк, возобновляем работу")
            bot.waiting_for_interval = False
            bot.interval_resume_time = None
            
            # Выполняем reset браузера
            fsm.reset_scenario(bot)
```

**Что происходит:**
- Основной цикл проверяет каждый бот
- Если `waiting_for_interval = True` — пропускает обработку
- Когда `current_time >= interval_resume_time` — сбрасывает флаг и выполняет reset

### Шаг 5: Возобновление работы

После истечения интервала:

```python
# fsm.reset_scenario(bot) выполняет:
# 1. Ctrl+L (выделение URL)
# 2. Ввод URL сайта
# 3. Enter
# 4. Ожидание загрузки страницы

# Бот готов к следующему вопросу!
```

## 📝 Важные детали

### 1. Отсчёт от начала вопроса

**Важно:** Интервал отсчитывается **от начала спрашивания предыдущего вопроса**, а не от получения ответа.

```
Вопрос #1:  00:00 ──────> 00:30 (получен ответ)
                        ↓
                        Прошло 30 секунд

Вопрос #2:  00:30 ──────> 01:00 (получен ответ)
                        ↓
                        Прошло 30 секунд

Интервал:   question_interval = 5.0
            30 > 5 → Интервал прошёл автоматически!
            → Бот сразу начинает вопрос #3
```

**Вывод:** Если вопрос занимает больше времени чем `question_interval`, то дополнительной задержки не будет.

### 2. question_interval = 0

```yaml
question_interval: 0  # или отсутствует
```

**Что происходит:**
- Проверка интервала пропускается
- Бот сразу переходит к следующему вопросу
- **Максимальная скорость работы**

### 3. Обработка в run_bot.py vs main.py

**main.py** (запуск всех ботов):
```python
# ✅ Обрабатывает waiting_for_interval
for bot_idx, (bot, fsm) in enumerate(zip(bots, logics)):
    if hasattr(bot, 'waiting_for_interval') and bot.waiting_for_interval:
        if current_time >= bot.interval_resume_time:
            # Возобновляет работу
```

**run_bot.py** (одиночный запуск):
```python
# ❌ НЕ обрабатывает waiting_for_interval
while True:
    if bot.stop_event.is_set():
        ...
    
    frame = bot.get_frame_umat()
    if frame is not None:
        fsm.execute_step(bot, analyzer, frame)
    
    time.sleep(1.0)  # ← Просто пауза 1 секунда
```

**Проблема:** При запуске через `run_bot.py` интервал **НЕ работает**! Бот не ждёт.

**Решение:** Добавить обработку в `run_bot.py`:

```python
# run_bot.py (обновлённая версия)
while True:
    current_time = time.time()
    
    # Проверка ожидания интервала
    if hasattr(bot, 'waiting_for_interval') and bot.waiting_for_interval:
        if hasattr(bot, 'interval_resume_time') and current_time >= bot.interval_resume_time:
            print(f"[+] [Бот {bot_index}] Интервал истёк, возобновляем работу")
            bot.waiting_for_interval = False
            bot.interval_resume_time = None
            fsm.reset_scenario(bot)
        else:
            time.sleep(0.5)  # Ждём
            continue
    
    # Остальная логика...
```

## 🎯 Когда использовать

### Короткий интервал (0-10 сек)

```yaml
question_interval: 5.0
```

**Для каких моделей:**
- Qwen
- Быстрые модели без "размышлений"

**Почему:**
- Модель отвечает быстро (~5-10 сек)
- Можно задавать вопросы почти без задержки

### Средний интервал (30-60 сек)

```yaml
question_interval: 45.0
```

**Для каких моделей:**
- GPT-4
- Claude

**Почему:**
- Модель думает ~20-40 сек
- Нужно время на генерацию ответа

### Длинный интервал (120-300 сек)

```yaml
question_interval: 220.0
```

**Для каких моделей:**
- Gemini Thinking
- Модели с режимом "размышления"

**Почему:**
- Модель думает ~60-180 сек
- Нужно ждать завершения "thinking process"

## 🔧 Настройка для вашего случая

### Формула расчёта

```
question_interval = (Среднее время генерации ответа) + 10% запас
```

**Пример:**
- GPT отвечает за ~40 секунд
- `question_interval = 40 + 4 = 44 секунды` → округляем до `45.0`

### Как подобрать

1. **Запустите бота** с текущим интервалом
2. **Наблюдайте за логами:**
   ```bash
   tail -f /tmp/bot0_test.log | grep "Ожидание интервала"
   ```
3. **Если видите:**
   ```
   [*] [Бот 0] Ожидание интервала между вопросами: 45.0с (интервал: 60.0с)
   ```
   → Уменьшите интервал (бот ждёт слишком долго)

4. **Если не видите сообщений об ожидании:**
   → Увеличьте интервал (бот не успевает получить ответ)

## 🐛 Проблемы и решения

### Проблема: Бот работает слишком медленно

**Симптомы:**
```
[*] [Бот 0] Ожидание интервала между вопросами: 55.0с (интервал: 60.0с)
```

**Решение:** Уменьшите `question_interval`:
```yaml
question_interval: 30.0  # Было 60.0
```

### Проблема: Бот не получает ответы

**Симптомы:**
- Частые ошибки верификации JSON
- Пустой буфер обмена

**Причина:** Бот начинает следующий вопрос раньше чем модель завершила генерацию

**Решение:** Увеличьте `question_interval`:
```yaml
question_interval: 90.0  # Было 45.0
```

### Проблема: question_interval не работает при одиночном запуске

**Симптомы:**
- Боты запущены через `run_bot.py`
- Нет сообщений "Ожидание интервала"
- Боты работают без задержек

**Причина:** `run_bot.py` не обрабатывает `waiting_for_interval`

**Решение:** Используйте `main.py` или добавьте обработку в `run_bot.py`
